# Проект: DJANGO

## Цель проекта
Обучение работы с Django.

## Реализовано

 - 2 html шаблона с подключенными стилями Bootstrap
 - Приложение Catalog
 - Создан контроллер для отображения домашней страницы 
 - Создан контроллер для отображения страницы контактов 
 - Зарегистрированы маршруты для контроллеров 
 - Маршруты приложения catalog подключены к корневым маршрутам
